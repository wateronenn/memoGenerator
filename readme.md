# Memorandum Generator Web App

## Overview

This Memorandum Generator Web App is a demonstration prototype intended for future deployment and enhancement.

## Deployment

**Vercel:**
https://memo-generator-sigma.vercel.app/memo_generator.html

## Running Locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the HTML files using a Live Server extension (e.g., VS Code Live Server).

## Notes

* This project is currently a demo/proof-of-concept version.
* The Claude API token is not available in this repository.
* All LLM-related functionality is currently mocked for demonstration purposes.
* The existing implementation simulates API calls for text generation and summarization without connecting to an actual AI service.
